### 图的设计原则

- **不靠颜色区分**：用灰度 + 填充图案（斜线 / 网格）+ 线型（实线 / 虚线）+ 标记形状（圆 / 菱形）四重编码，黑白打印与缩小显示都能读
- **图内只有数据**：只保留坐标轴、数据、图例与必要的数值标注；结论与解说全部移到 `figures.md`
- **文字不压图形**：所有标注都经过几何检测（文字与文字重叠、文字压填充图元、折线穿文字、越界四类）并用真实字形宽度校准，12 张图均为 0 问题
- **字号下限 9pt**，中文宋体、英文 Times New Roman

## 数据口径

所有图表的数据来自同一评测卷：**365 条记录 / 2,394 道题**（SAS-Bench 来源的中文 K-12 学科主观题），除图 8（数据集构成）外均为本机实测。

原始日志与出图脚本未随本仓库发布；每个数字的来源文件名已在 `technical-report.md` 文末的「数据来源」表中列出，便于读者判断哪些结论可复算。

## 关于图中的 System2 / 云端部分

图 1、图 6、图 7、图 9 涉及「本地模型 + 云端模型选择性复核」的双 System 架构。这部分描述的是**方法与实测结果**，相关代码与云端调用脚本未包含在本仓库中（涉及第三方商业 API）。本地模型本身（`infer.py` + 权重）可完全离线运行，不依赖云端。
